# NoteBookEngine



## 概要

DirectX11で制作したノベルゲームエンジンです。



## 技術スタック

- C、C++

- DirectX11

- XAudio2

- ImGui

- yaml-cpp

- Visual Studio 2022



## 制作目的

専門学校3年の春に、ノベルゲーム制作をしたのがきっかけでした。
ノベルゲーム制作をしているうちに、自分でもエンジンを制作したいと感じ、制作を始めました。



## 工夫した点

ゲームエンジンは、操作が容易であることが重要と感じた為、ドラッグだけで制作できる簡単なエンジンに仕上げました。  
また、ノベルゲームではキャラのイラストを沢山描きますが、イラスト制作ソフトから出力される画像色空間（色を数値で表現するための空間）がガンマ色空間となっているものがほとんどということが制作中に分かりました。その為、エンジンでの描画設定をSRGBにしておくことで、わざわざ画像編集ソフトを通して色空間を修正する手間を省くような設計としました。



## 得られた学び

今回の制作を通して、改めて既存のゲームエンジンの凄さが伝わりました。
UIをどう置けばユーザーは直感的に触れるか、豊富な機能の実装など、既存のゲームエンジンの完成度の高さを改めて感じました。
また、ゲームエンジンの制作を通して、ゲームエンジンの構造や、ゲーム制作に必要な機能などを学ぶことが出来ました。
